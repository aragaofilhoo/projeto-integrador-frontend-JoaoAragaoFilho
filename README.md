# projeto-integrador-frontend-JoaoAragaoFilho
===== APRESENTAÇÃO DO PROJETO =====
    
    Este projeto é um gerador de senha comum, uma ferramenta rápida, gratuita e amplamente utilizada em diferentes tipos de Aplicação como forma de assegurar o login e informações pessoais do usuário e com isso, garantir a proteção digital.
    A partir dele, qualquer usuário pode criar senhas fortes, como bem desejar, ao obedecer os critérios mínimos estabelecidos.
    A ferramenta de que trata este projeto pode ser anexada por link e acessada externamente, ou até mesmo dentro de uma aba/recurso da própria aplicação.

    ***** Foram utilizados os recursos externos de:
            ° https://convertio.co/pt/audio-converter/: para conversão da gravação do aúdio de Chopin, agregado ao site;
            ° https://www.flaticon.com/br/icones-animados-gratis: para encontrar um gif de cadeado com senha;
            °https://claude.ai: para auxílio no desenvolvimento web como todo.
